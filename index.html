Full Arduino Code

The following code controls the entire smart traffic light system including LEDs, IR sensor, OLED displays, RFID module, and push button.

Full Colored Arduino Code

#include <Wire.h>                  // Used for I2C communication. The OLED screens use I2C.
#include "SSD1306Ascii.h"          // Library used to print text on SSD1306 OLED displays.
#include "SSD1306AsciiWire.h"      // Allows the SSD1306 OLED to work using the Wire I2C library.
#include <SPI.h>                   // Used for SPI communication. The RFID module uses SPI.
#include <MFRC522.h>               // Library used to control the RFID RC522 module.


// ---------------- 1. DISPLAY SETUP ----------------

// This creates an object for the first OLED screen.
// This OLED is used to show car traffic information.
SSD1306AsciiWire displayCars;

// This creates an object for the second OLED screen.
// This OLED is used to show pedestrian information.
SSD1306AsciiWire displayPed;


// ---------------- 2. PIN DEFINITIONS ----------------

// The pedestrian push button is connected to Arduino digital pin 2.
// We use this button when a pedestrian wants to cross.
const int BUTTON_PIN = 2;

// The red LED is connected to Arduino digital pin 3.
// Red means cars must stop.
const int RED_LED = 3;

// The yellow LED is connected to Arduino digital pin 4.
// Yellow means caution / prepare to stop or go.
const int YELLOW_LED = 4;

// The green LED is connected to Arduino digital pin 6.
// Green means cars can move.
const int GREEN_LED = 6;

// The IR sensor is connected to Arduino digital pin 5.
// It detects cars passing in front of it.
const int IR_SENSOR = 5;

// The buzzer is connected to Arduino digital pin 7.
// It turns on when a car violates the red light.
const int BUZZER_PIN = 7;

// RFID reset pin.
// This pin is used by the RFID module to reset communication.
#define RST_PIN 9

// RFID slave select pin.
// This pin is used to choose the RFID module during SPI communication.
#define SS_PIN 10

// This creates an RFID object called rfid.
// The object uses SS_PIN and RST_PIN to communicate with the RFID module.
MFRC522 rfid(SS_PIN, RST_PIN);


// ---------------- 3. STATE VARIABLES ----------------

// This variable counts how many vehicles passed in front of the IR sensor.
// int is used because the value is a whole number.
int vehicleCount = 0;

// This variable checks if a car is currently in front of the IR sensor.
// bool means true or false only.
// false = no car currently detected.
// true = car currently detected.
bool isCarPresent = false;

// This variable stores if the pedestrian button was pressed.
// false = no request.
// true = pedestrian wants to cross.
bool pedestrianRequest = false;

// This variable stores the time when the buzzer should turn off.
// unsigned long is used because millis() returns a very large positive number.
// millis() counts time in milliseconds since Arduino started.
// int is too small for this, so unsigned long is safer.
unsigned long buzzerTurnOffTime = 0; 


// This enum stores the current traffic light state.
// enum makes the code easier to read instead of using numbers like 0, 1, 2.
enum LightState { GREEN, YELLOW, RED };

// This variable stores the current light color.
// The system starts with green.
LightState currentState = GREEN;


// This enum stores the phase of the full traffic cycle.
// P_GREEN    = green phase.
// P_YELLOW_1 = yellow after green.
// P_RED      = red phase.
// P_YELLOW_2 = yellow after red.
enum CyclePhase { P_GREEN, P_YELLOW_1, P_RED, P_YELLOW_2 };

// This variable stores which phase the system is currently running.
// The system starts with the green phase.
CyclePhase currentPhase = P_GREEN;


// This stores the text that will appear on the car OLED.
// const char* is used for text.
// It is lighter than String and better for Arduino memory.
const char* currentCarText = "";

// This stores the countdown number for the car OLED.
int currentCarSec = 0;

// This stores the text that will appear on the pedestrian OLED.
const char* currentPedText = "";

// This stores the countdown number for the pedestrian OLED.
int currentPedSec = 0;


// ---------------- SETUP FUNCTION ----------------

void setup() {

    // Start Serial Monitor communication at speed 9600.
    // This lets us print messages to the computer for testing.
    Serial.begin(9600);

    // Print a starting message on the Serial Monitor.
    Serial.println("System Starting...");

    // Set the red LED pin as OUTPUT because Arduino sends electricity to the LED.
    pinMode(RED_LED, OUTPUT);

    // Set the yellow LED pin as OUTPUT.
    pinMode(YELLOW_LED, OUTPUT);

    // Set the green LED pin as OUTPUT.
    pinMode(GREEN_LED, OUTPUT);

    // Set the button pin as INPUT_PULLUP.
    // INPUT_PULLUP means Arduino uses an internal resistor.
    // The button reads HIGH normally.
    // When the button is pressed, it reads LOW.
    pinMode(BUTTON_PIN, INPUT_PULLUP);

    // Set the IR sensor pin as INPUT because Arduino reads data from the sensor.
    pinMode(IR_SENSOR, INPUT);

    // Set the buzzer pin as OUTPUT because Arduino controls the buzzer.
    pinMode(BUZZER_PIN, OUTPUT);

    // Make sure the buzzer is OFF at the beginning.
    digitalWrite(BUZZER_PIN, LOW);

    // Start SPI communication for the RFID module.
    SPI.begin();

    // Start and initialize the RFID reader.
    rfid.PCD_Init();

    // Start I2C communication for the OLED screens.
    Wire.begin();

    // Set I2C speed to 400000 Hz.
    // This makes OLED communication faster.
    Wire.setClock(400000L);

    // Start the first OLED display.
    // 0x3C is the I2C address of the car OLED.
    displayCars.begin(&Adafruit128x64, 0x3C);

    // Set the font used on the car OLED.
    displayCars.setFont(Adafruit5x7);

    // Clear anything written on the car OLED.
    displayCars.clear();

    // Start the second OLED display.
    // 0x3D is the I2C address of the pedestrian OLED.
    displayPed.begin(&Adafruit128x64, 0x3D);

    // Set the font used on the pedestrian OLED.
    displayPed.setFont(Adafruit5x7);

    // Clear anything written on the pedestrian OLED.
    displayPed.clear();

    // Print ready message on Serial Monitor.
    Serial.println("System Ready!");
}


// ---------------- MAIN LOOP ----------------

void loop() {

    // This variable becomes true if RFID emergency card is detected.
    // It starts as false every loop.
    bool emergencyTriggered = false;

    // If the current phase is green, run the green phase.
    if (currentPhase == P_GREEN) {

        // Run green phase.
        // If RFID is detected during it, this function returns true.
        emergencyTriggered = runGreenPhase();

        // After green ends, go to first yellow phase.
        currentPhase = P_YELLOW_1;
    }

    // If the current phase is first yellow.
    else if (currentPhase == P_YELLOW_1) {

        // Run yellow phase.
        emergencyTriggered = runYellowPhase();

        // After yellow ends, go to red phase.
        currentPhase = P_RED;
    }

    // If the current phase is red.
    else if (currentPhase == P_RED) {

        // Run red phase.
        emergencyTriggered = runRedPhase();

        // After red ends, go to second yellow phase.
        currentPhase = P_YELLOW_2;
    }

    // If the current phase is second yellow.
    else if (currentPhase == P_YELLOW_2) {

        // Run yellow phase again.
        emergencyTriggered = runYellowPhase();

        // After yellow ends, return to green phase.
        currentPhase = P_GREEN;
    }

    // If emergency RFID was detected in any phase.
    if (emergencyTriggered) {

        // Run emergency override mode.
        handleEmergency();

        // After emergency finishes, continue from red phase.
        currentPhase = P_RED;
    }
}


// ==================== TRAFFIC PHASES ====================


// ---------------- GREEN PHASE ----------------

bool runGreenPhase() {

    // Save the current traffic light state as GREEN.
    currentState = GREEN;

    // Turn green LED ON.
    digitalWrite(GREEN_LED, HIGH);

    // Turn yellow LED OFF.
    digitalWrite(YELLOW_LED, LOW);

    // Turn red LED OFF.
    digitalWrite(RED_LED, LOW);

    // At the start of green, reset pedestrian request.
    // This means no pedestrian request exists yet.
    pedestrianRequest = false;

    // Countdown from 30 seconds to 1 second.
    for (int i = 30; i > 0; i--) {

        // Text shown on car OLED.
        currentCarText = "GO";

        // Countdown shown on car OLED.
        currentCarSec = i;

        // Text shown on pedestrian OLED.
        // Pedestrians must wait while cars are moving.
        currentPedText = "WAIT";

        // No countdown is shown for pedestrians during green.
        currentPedSec = 0;

        // Update both OLED screens with the new text and time.
        updateUI();

        // Wait 1 second, but during this second keep checking:
        // - IR sensor
        // - buzzer timer
        // - pedestrian button
        // - RFID emergency card
        //
        // 1000 = 1000 milliseconds = 1 second
        // true = check button
        // true = check RFID
        //
        // If emergency RFID is detected, the function returns true.
        if (waitAndCheckSensors(1000, true, true)) return true;

        // If pedestrian button was pressed during green.
        if (pedestrianRequest) {

            // Print message to Serial Monitor.
            Serial.println(">>> Pedestrian Button Pressed! Stopping traffic...");

            // Stop green countdown early so system can move to yellow then red.
            break;
        }
    }

    // Turn green LED OFF when green phase finishes.
    digitalWrite(GREEN_LED, LOW);

    // Return false because no emergency happened.
    return false;
}


// ---------------- YELLOW PHASE ----------------

bool runYellowPhase() {

    // Save current light state as YELLOW.
    currentState = YELLOW;

    // Turn yellow LED ON.
    digitalWrite(YELLOW_LED, HIGH);

    // Countdown from 3 seconds to 1 second.
    for (int i = 3; i > 0; i--) {

        // Show caution message to cars.
        currentCarText = "CAUTION";

        // Show remaining yellow time.
        currentCarSec = i;

        // Pedestrians still wait during yellow.
        currentPedText = "WAIT";

        // No pedestrian countdown during yellow.
        currentPedSec = 0;

        // Update OLED screens.
        updateUI();

        // Wait 1 second and check sensors.
        // false = do not check pedestrian button during yellow.
        // true = check RFID emergency card.
        if (waitAndCheckSensors(1000, false, true)) return true;
    }

    // Turn yellow LED OFF after yellow phase finishes.
    digitalWrite(YELLOW_LED, LOW);

    // Return false because no emergency happened.
    return false;
}


// ---------------- RED PHASE ----------------

bool runRedPhase() {

    // Save current light state as RED.
    currentState = RED;

    // Turn red LED ON.
    digitalWrite(RED_LED, HIGH);

    // Countdown from 30 seconds to 1 second.
    for (int i = 30; i > 0; i--) {

        // Tell cars to stop.
        currentCarText = "STOP";

        // Show remaining red time for cars.
        currentCarSec = i;

        // Tell pedestrians they can cross.
        currentPedText = "CROSS";

        // Show pedestrian countdown.
        currentPedSec = i;

        // Update OLED screens.
        updateUI();

        // Wait 1 second and keep checking:
        // - IR sensor
        // - buzzer
        // - RFID emergency
        //
        // false = no pedestrian button check during red.
        // true = check RFID.
        if (waitAndCheckSensors(1000, false, true)) return true;
    }

    // Turn red LED OFF when red phase ends.
    digitalWrite(RED_LED, LOW);

    // Return false because no emergency happened.
    return false;
}


// ---------------- EMERGENCY MODE ----------------

void handleEmergency() {

    // Print emergency message on Serial Monitor.
    Serial.println(">>> EMERGENCY OVERRIDE TRIGGERED <<<");

    // If emergency happens while the light is red.
    if (currentState == RED) {

        // Turn red LED OFF.
        digitalWrite(RED_LED, LOW);

        // Turn yellow LED ON before switching to emergency green.
        digitalWrite(YELLOW_LED, HIGH);

        // Update current state to yellow.
        currentState = YELLOW;

        // Short warning yellow countdown for 3 seconds.
        for (int i = 3; i > 0; i--) {

            // Show emergency message on car OLED.
            currentCarText = "EMERG.";

            // Show countdown.
            currentCarSec = i;

            // Pedestrians must wait.
            currentPedText = "WAIT";

            // No pedestrian countdown here.
            currentPedSec = 0;

            // Update OLED screens.
            updateUI();

            // Wait 1 second.
            // false, false means do not check button or RFID during this emergency transition.
            waitAndCheckSensors(1000, false, false);
        }

        // Turn yellow OFF.
        digitalWrite(YELLOW_LED, LOW);
    }

    // If emergency happens while light is yellow.
    else if (currentState == YELLOW) {

        // Turn yellow OFF immediately.
        digitalWrite(YELLOW_LED, LOW);
    }

    // Emergency road becomes green.
    currentState = GREEN;

    // Turn green LED ON for emergency vehicle.
    digitalWrite(GREEN_LED, HIGH);

    // Make sure red LED is OFF.
    digitalWrite(RED_LED, LOW);

    // Emergency green countdown for 30 seconds.
    for (int i = 30; i > 0; i--) {

        // Tell emergency vehicle to go.
        currentCarText = "EMERG. GO";

        // Show countdown on car OLED.
        currentCarSec = i;

        // Pedestrians must stop during emergency.
        currentPedText = "STOP";

        // Show countdown on pedestrian OLED.
        currentPedSec = i;

        // Update OLED screens.
        updateUI();

        // Wait 1 second.
        // No button or RFID checking during emergency green.
        waitAndCheckSensors(1000, false, false);
    }

    // Turn green OFF after emergency green finishes.
    digitalWrite(GREEN_LED, LOW);

    // Change state to yellow after emergency green.
    currentState = YELLOW;

    // Turn yellow ON.
    digitalWrite(YELLOW_LED, HIGH);

    // Yellow countdown for 3 seconds after emergency.
    for (int i = 3; i > 0; i--) {

        // Show caution message.
        currentCarText = "CAUTION";

        // Show countdown.
        currentCarSec = i;

        // Pedestrians wait.
        currentPedText = "WAIT";

        // No pedestrian countdown.
        currentPedSec = 0;

        // Update OLED screens.
        updateUI();

        // Wait 1 second.
        waitAndCheckSensors(1000, false, false);
    }

    // Turn yellow OFF.
    digitalWrite(YELLOW_LED, LOW);
}


// ==================== SENSOR LOGIC ====================

bool waitAndCheckSensors(unsigned long duration, bool checkButton, bool checkRFID) {

    // Store the time when this waiting period starts.
    // millis() returns the time since Arduino started in milliseconds.
    // unsigned long is used because millis() can become a very large number.
    unsigned long startMillis = millis();

    // Store the last time RFID was checked.
    // This is used so RFID is not checked too many times every millisecond.
    unsigned long lastRFIDCheck = 0;

    // Keep looping until the required duration finishes.
    // Example:
    // if duration = 1000, this loop runs for 1 second.
    while (millis() - startMillis < duration) {

        // ---------------- BUZZER TIMER ----------------

        // If the current time is still less than buzzerTurnOffTime,
        // that means the buzzer should stay ON.
        if (millis() < buzzerTurnOffTime) {

            // Turn buzzer ON.
            digitalWrite(BUZZER_PIN, HIGH);
        }

        // If the current time passed buzzerTurnOffTime,
        // that means buzzer time finished.
        else {

            // Turn buzzer OFF.
            digitalWrite(BUZZER_PIN, LOW);
        }

        // ---------------- IR SENSOR ----------------

        // Read the IR sensor.
        // HIGH means car detected.
        // LOW means no car detected.
        int irVal = digitalRead(IR_SENSOR);

        // If the IR sensor detects a car
        // AND this car was not already counted before.
        if (irVal == HIGH && !isCarPresent) {

            // Mark that a car is now present.
            isCarPresent = true;

            // Increase the vehicle count by 1.
            vehicleCount++;

            // Print text on Serial Monitor.
            Serial.print("Car Count: ");

            // Print the new vehicle count.
            Serial.println(vehicleCount);

            // If a car passes while the light is red,
            // this is a red light violation.
            if (currentState == RED) {

                // Print violation message.
                Serial.println("!!! RED LIGHT VIOLATION !!!");

                // Turn buzzer on for 3 seconds from the current time.
                // millis() = current time.
                // +3000 = add 3000 milliseconds = 3 seconds.
                buzzerTurnOffTime = millis() + 3000;
            }

            // Update OLED screens because vehicle count changed.
            updateUI();
        }

        // If the IR sensor does not detect a car.
        else if (irVal == LOW) {

            // Allow the next car to be counted.
            // Without this, the system may count one car many times.
            isCarPresent = false;
        }

        // ---------------- PEDESTRIAN BUTTON ----------------

        // Check the pedestrian button only if checkButton is true.
        // The button uses INPUT_PULLUP, so pressed = LOW.
        if (checkButton && digitalRead(BUTTON_PIN) == LOW) {

            // Small delay for button debounce.
            // Debounce prevents false readings from button vibration.
            delay(50);

            // Check again to make sure the button is really pressed.
            if (digitalRead(BUTTON_PIN) == LOW) {

                // Save that pedestrian requested crossing.
                pedestrianRequest = true;

                // Return false because this is not an emergency.
                return false;
            }
        }

        // ---------------- RFID CHECK ----------------

        // Check RFID only if checkRFID is true.
        // Also check only every 100 milliseconds to avoid checking too fast.
        if (checkRFID && (millis() - lastRFIDCheck >= 100)) {

            // If emergency RFID card is detected.
            if (checkForEmergency()) {

                // Return true because emergency happened.
                return true;
            }

            // Save the current time as the last RFID check time.
            lastRFIDCheck = millis();
        }

        // Very small delay to make Arduino stable.
        delay(1);
    }

    // The duration finished and no emergency happened.
    return false;
}


// ---------------- CHECK RFID EMERGENCY ----------------

bool checkForEmergency() {

    // Check if there is a new RFID card near the reader
    // AND if the card serial can be read.
    if (rfid.PICC_IsNewCardPresent() && rfid.PICC_ReadCardSerial()) {

        // Stop communication with this RFID card.
        rfid.PICC_HaltA();

        // Return true because an emergency card was detected.
        return true;
    }

    // Return false if no RFID card was detected.
    return false;
}


// ==================== OLED UI UPDATE ====================

void updateUI() {

    // Clear the car OLED before writing new data.
    displayCars.clear();

    // Make text double size on car OLED.
    displayCars.set2X();

    // Print "CAR: " label.
    displayCars.print("CAR: ");

    // Print the current car message:
    // GO, STOP, CAUTION, EMERG., or EMERG. GO.
    displayCars.println(currentCarText);

    // Print empty line.
    displayCars.println();

    // Print "TIME: " label.
    displayCars.print("TIME: ");

    // Print the countdown seconds for cars.
    displayCars.println(currentCarSec);

    // Return text size to normal.
    displayCars.set1X();

    // Print empty line.
    displayCars.println();

    // Print vehicle counter label.
    displayCars.print("VEHICLES: ");

    // Print number of counted vehicles.
    displayCars.println(vehicleCount);


    // Clear pedestrian OLED before writing new data.
    displayPed.clear();

    // Set normal text size.
    displayPed.set1X();

    // Print title on pedestrian OLED.
    displayPed.println("PEDESTRIAN");

    // Print empty line.
    displayPed.println();

    // Make pedestrian status text bigger.
    displayPed.set2X();

    // Print pedestrian message:
    // WAIT, CROSS, or STOP.
    displayPed.println(currentPedText);

    // If pedestrian countdown is greater than 0,
    // show the countdown number.
    if (currentPedSec > 0) {

        // Print opening bracket.
        displayPed.print("(");

        // Print countdown seconds.
        displayPed.print(currentPedSec);

        // Print closing bracket.
        displayPed.println(")");
    }
}

Project Overview

What does this project do?

This project is a Smart Traffic Light System using an Arduino UNO. The Arduino controls the red, yellow, and green LEDs, reads an IR sensor to detect cars, counts vehicles, reads a push button for pedestrian crossing, uses a buzzer for red-light violations, shows information on OLED displays, and uses RFID to give emergency vehicles priority.

Simple idea: Sensors give information to the Arduino. The Arduino thinks using the code. Then it controls LEDs, buzzer, OLED, and emergency mode.

Arduino UNO

What is Arduino UNO?

Arduino UNO is a small electronic board. It works like the brain of the project. It has a microcontroller called ATmega328P. The microcontroller stores and runs your code.

Input

Arduino reads signals from sensors or buttons. Example: IR sensor detects a car, button detects pedestrian request.

Processing

Arduino makes decisions using code. Example: if red light is ON and car passes, turn buzzer ON.

Output

Arduino controls devices. Example: LEDs, buzzer, OLED display, RFID communication.

What is a microcontroller?

A microcontroller is a tiny computer inside the Arduino. It has a CPU, memory, and input/output control. It is not like a laptop, but it is perfect for controlling electronic circuits.

Digital Pins

Digital Pins Explained

Digital pins are pins that understand only two states: HIGH and LOW. HIGH means 5V, and LOW means 0V.

StateVoltageMeaningExample
HIGH5VON / TRUE / 1LED turns ON
LOW0VOFF / FALSE / 0LED turns OFF

Digital Output

Used when Arduino controls something, like an LED or buzzer.

digitalWrite(RED_LED, HIGH); // Red LED ON
digitalWrite(RED_LED, LOW);  // Red LED OFF

Digital Input

Used when Arduino reads something, like a button or IR sensor.

int buttonState = digitalRead(BUTTON_PIN);
Analog Pins

Analog Pins Explained

Analog pins are A0, A1, A2, A3, A4, and A5. They can read a range of voltage values, not only ON/OFF. Arduino converts the voltage into a number from 0 to 1023 using an ADC.

Analog ReadingApprox VoltageMeaning
00VNo voltage
512About 2.5VMiddle value
1023About 5VMaximum voltage

Important: In your project, A4 and A5 are not used as normal analog inputs. They are used for OLED I2C communication.

int sensorValue = analogRead(A0); // Reads value from 0 to 1023
PWM

PWM Pins Explained

PWM means Pulse Width Modulation. It is used to make a digital pin act like analog output. Arduino does this by switching the pin ON and OFF very fast.

More ON time: LED becomes brighter or motor becomes faster.
Less ON time: LED becomes dimmer or motor becomes slower.
PWM value range: 0 to 255.
PWM ValueEffect
0Always OFF
127About half power
255Always ON

On Arduino UNO, PWM pins are marked with ~: 3, 5, 6, 9, 10, and 11.

analogWrite(RED_LED, 120); // Red LED medium brightness

Important: PWM is output only. It is not the same as analog input.

Easy Explanation to Say in Your Discussion

The Arduino UNO is the controller of my project. It uses a microcontroller called ATmega328P to run the code. Some pins are inputs, like the push button on pin 2 and the IR sensor on pin 5. These pins send information to the Arduino. Other pins are outputs, like the LEDs and buzzer. The Arduino sends HIGH or LOW to turn them ON or OFF.

The OLED display uses I2C communication through A4 and A5. A4 is SDA, which sends data, and A5 is SCL, which sends the clock. The RFID module uses SPI communication through pins 10, 11, 12, and 13, plus pin 9 for reset. The RFID works with 3.3V, so it should not be connected to 5V.

Digital pins work with HIGH and LOW only. Analog pins read values from 0 to 1023. PWM pins can control brightness or speed by switching ON and OFF very fast. In this project, Arduino combines digital input, digital output, I2C, SPI, and real-time logic.
